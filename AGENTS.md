# Contrat Agents & LLM — GhostMeta

Ce fichier définit les règles de gouvernance, de sécurité et d'interaction pour tout agent IA opérant dans GhostMeta.

---

## 1. Confinement & Isolation

- **Périmètre strict :** Opérer uniquement à l'intérieur du dossier racine de ce projet (`GhostMeta`).
- **Interdiction formelle :** Ne jamais modifier ou supprimer des fichiers dans le dossier parent ou les projets voisins.

---

## 2. Rôle du Projet

- GhostMeta est une application locale de suppression zéro-trace de métadonnées et de tags de traçabilité IA (C2PA, Content Credentials, EXIF, XMP, IPTC) pour photos, films/vidéos, PNG et audio.
- Port local de référence : **8780**.
